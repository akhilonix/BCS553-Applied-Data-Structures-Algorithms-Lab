## Contents
This repository contains all 15 lab assignments (46 Java task programs) based on the supplied BCS553 assignment sheet. Each task folder contains:
- `Main.java` – complete Java source code
- `output.txt` – expected program output

## Run a program
Open a task folder in a terminal and run:

```bash
javac Main.java
java Main
```

Requires JDK 8 or later. Each task is kept in a separate folder because all programs use the class name `Main`.
